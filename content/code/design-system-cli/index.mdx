## Overview

Design tokens are essential for maintaining consistency across products, but keeping documentation and components in sync with tokens is a manual effort. This CLI automates the pipeline.

## Technical Details

The tool reads JSON token files (compatible with the Design Tokens Format), validates them against a schema, and generates TypeScript types, CSS variables, component scaffolding, and documentation.

Built with a plugin architecture so teams can extend it with their own generators.
